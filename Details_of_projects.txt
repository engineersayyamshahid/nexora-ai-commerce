3: Then i install the shadcn :  npx shadcn@latest init
    To install any component in project of shadcn. 
    Follow this :  npx shadcn@latest add card badge dialog input label separator table textarea 
    npx shadcn@latest add carousel checkbox collapsible command  popover radio-group scroll-area tooltip

4: Then i make the Header, Footer and Container File in component Folder. 
     Think of a Container as a box that keeps all your website content aligned and prevents it from stretching across the entire screen.
     Without a container:   
     -------------------------------------------------------------
     This text starts from the very left and goes to the very right.
     -------------------------------------------------------------

     With a container:

     -------------------------------------------------------------
        This text stays nicely in the center
        with space on both sides.
    -------------------------------------------------------------
     That's why almost every website has a container.
